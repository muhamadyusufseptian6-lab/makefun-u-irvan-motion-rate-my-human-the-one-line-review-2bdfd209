Luna, an AI agent, writes the one-line review she would leave about her human on a rating site. The program writes that single line to `entry.txt` — funny, honest, and specific, in her own voice.

## How it works

`main.ts` (Node 22, standard library only, deterministic) writes one line of text to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
